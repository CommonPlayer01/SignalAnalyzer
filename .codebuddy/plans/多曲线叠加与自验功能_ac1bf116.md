## 产品概述
在现有 Qt 信号分析器中扩展两项能力：一是在 UI 上支持**多条曲线叠加对比**（勾选框式叠加 + 清空），二是一个**自验功能**（内置生成已知 f/A/fs/N 的正弦，界面显示理论 vs 检测值对照）。同时配套「整周期/非整周期」泄漏对比样本与演示文档，用叠加功能直观验证加窗对频谱泄漏的抑制作用。

## 核心功能
- **多曲线叠加**：顶部新增「叠加对比」勾选框与「清空曲线」按钮。勾选后，切换文件/信号类型/窗函数产生的新曲线会**追加**到图上（旧曲线保留），可逐步叠出 2~4 条，不同颜色 + 图例区分；不勾选时替换为单曲线；「清空曲线」一键清除所有叠加曲线。
- **自验弹窗**：点「自验」弹出对话框，可输入频率 f、幅值 A、采样率 fs、点数 N，点击「生成并检测」由后台生成对应正弦、做幅值谱并检测谱峰；对话框以表格显示「理论值 / 检测值 / 偏差」对照；勾选「叠加到主图」可把该谱曲线叠加到主绘图区。
- **泄漏对比演示**：新增整周期（128 Hz）与非整周期（128.5 Hz）两个正弦样本文件，配合叠加功能，把「矩形窗谱 / 汉宁窗谱」或「整周期 / 非整周期」叠在同图对比；编写演示文档说明操作与预期现象。

## 视觉预期
- 顶部控制栏在原有「导入/文件/信号/窗函数」之后，新增「叠加对比」勾选框、「清空曲线」按钮、「自验」按钮，风格与现有控件一致。
- 叠加时多条曲线以蓝/橙/绿/红四色循环绘制，图例在右上角标明各自标签（如「文件名·窗函数·信号类型」「自验 f=128Hz A=1」）。
- 自验对话框为简洁表单：四个数值输入框 + 「生成并检测」按钮 + 「叠加到主图」勾选框 + 一张对照表（理论值/检测值/偏差）。
- 整周期 + 矩形窗为干净单峰；非整周期 + 矩形窗旁瓣明显抬高；非整周期 + 汉宁窗旁瓣大幅下降、主瓣变宽。


## 技术栈选择
- 复用现有工程：**Qt 5.15.2 Widgets + QCustomPlot 2.1.1 + C++17 + CMake（MSVC v142）**。
- 算法复用 `SignalCoreLib`：`SpectrumAnalyzer::amplitudeSpectrum(data, window)` 已支持矩形/汉宁窗并输出谱峰，`WindowFactory::create("rect"/"hann")`。
- 分层与线程模型不变：UI 薄客户端 → `SignalWorker`（后台线程 + 代际号）→ `ComputeTask`（计算）→ 结果回传。

## 实现方法
- **多曲线绘制**：把 `PlotController` 从「固定 graph(0)」改为「多 graph 管理」：`setResult()`（先清空再画一条）、`appendResult()`（追加一条）、`clear()`（清空全部曲线数据）；用 `QCustomPlot::addGraph()` 按需增长，维护 `QVector<QCPGraph*>`，按 4 色调色板循环配色，图例名取结果标签，横/纵轴标签随最近一条结果更新。
- **数据模型扩展**：`ComputeRequest` 增加内置信号参数（`bool useBuiltin; double builtinFreq/builtinAmp/builtinFs; std::size_t builtinN;`）与 `QString label`；`ComputeResult` 增加 `bool builtin` 与 `QString label`。标签在 UI 侧生成、随请求→结果透传，避免在异步回调里读取已变化的控件状态导致图例错位。
- **内置正弦生成**：在 `ComputeTask::onComputeRequest` 增加分支——若 `useBuiltin`，用 `std::sin(2π f i / fs)` 生成 `samples`、构造 `SignalData(fs, std::move(samples))`，跳过文件读取；随后与文件路径共用同一套加窗、幅值谱、谱峰检测与 RMS 计算逻辑，并置 `result.builtin=true`。
- **自验弹窗**：新增 `SelfTestDialog`（QDialog，含 f/A/fs/N 输入、「生成并检测」按钮、「叠加到主图」勾选框、QTableWidget 对照表）。通过信号 `selfTestRequested(f,A,fs,N,overlay)` 通知 `SignalAnalyzer` 发起内置请求；结果回来时由 `SignalAnalyzer` 调用 `applyDetection(detFreq, detMag)` 回填对照表（理论值取自弹窗保存的输入）。
- **叠加交互**：`SignalAnalyzer` 依据 `chkOverlay->isChecked()` 决定 `onComputeFinished` 走 `appendResult` 还是 `setResult`；`btnClearCurves` 调 `m_plotController->clear()`；`btnSelfTest` 打开弹窗。失败分支在叠加模式下不清除已有曲线，仅状态栏报错。

## 关键决策与权衡
- **复用同一计算链路**：自验请求与文件请求都走 `SignalWorker → ComputeTask`，复用代际号过滤与加窗/谱峰逻辑，避免另起一套计算线程与重复代码。
- **标签随请求透传**：相比在 `onComputeFinished` 里读 `comboFile/comboWindow`，把标签放进请求/结果更可靠（异步结果可能对应较早的 UI 状态）。
- **内置正弦生成放 `ComputeTask`**：仅需一个小工具函数，避免扩大 `SignalCoreLib` 公共 API；样本文件由独立脚本生成，二者互不依赖。
- **非模态弹窗**：自验对话框用非模态 `show()`，让用户在查看对照表的同时观察主图叠加效果。

## 性能与可靠性
- 曲线数据量由现有 `downsampleForDisplay` 控制，叠加条数为 2~4 条，无热路径风险；`appendResult` 复用/增长 graph 而非无限重建。
- 新字段均为标量/`QString`，可直接跨线程 Queued 传递，`Q_DECLARE_METATYPE(ComputeRequest/ComputeResult)` 保持不变。
- 保持 `/utf-8` 编译设置与中文注释风格；代际号仅丢弃在途旧请求，UI 侧已采纳的叠加曲线不受影响。

## 关键代码结构
```cpp
// SignalTypes.h 扩展
struct ComputeRequest {
    QString filePath;                 // 内置信号时可为空
    SignalType signalType = SignalType::TimeDomain;
    QString windowName;               // "rect" / "hann"
    bool   useBuiltin = false;        // 是否使用内置正弦
    double builtinFreq = 0.0;         // Hz
    double builtinAmp  = 0.0;
    double builtinFs   = 0.0;         // Hz
    std::size_t builtinN = 0;
    QString label;                    // 图例名（由 UI 生成并透传）
};
// ComputeResult 追加：bool builtin = false; QString label;

// PlotController 多曲线接口
class PlotController : public QObject {
public:
    explicit PlotController(QCustomPlot* plot, QObject* parent = nullptr);
    void setResult(const ComputeResult& result);    // 替换：清空后画一条
    void appendResult(const ComputeResult& result); // 追加一条
    void clear();                                   // 清空所有曲线
private:
    QCPGraph* acquireGraph() ;                       // 按需 addGraph，循环 4 色
    QCustomPlot* m_plot;
    QVector<QCPGraph*> m_graphs;
    int m_curveCount = 0;
};
```


## 设计风格
沿用现有浅色桌面工具风格，强调「功能清晰、对照直观」，在原有顶部控制栏右侧自然加入叠加与自验入口，不改变整体布局骨架。

## 控制栏改造
在 `QHBoxLayout` 现有控件（导入、文件、信号、窗函数）之后，于 spacer 之前依次放置：
- `QCheckBox`「叠加对比」：勾选后切换配置时新曲线追加、旧曲线保留。
- `QPushButton`「清空曲线」：清除所有叠加曲线。
- `QPushButton`「自验」：打开自验对话框。

## 多曲线视觉
- 4 色调色板循环：蓝 #1E78C8、橙 #F08A24、绿 #2FA84F、红 #D64545，与现有蓝色笔触风格一致。
- 图例保持右上角，条目名取自曲线标签（文件名·窗函数·信号类型 / 自验 f..A..），便于区分。
- 横纵轴标签随最近一条结果显示（时域=秒、频谱=Hz）。

## 自验对话框
- 非模态 `QDialog`，标题「自验：理论 vs 检测」，`QFormLayout` 布置四行：频率 f(Hz)、幅值 A、采样率 fs(Hz)、点数 N（QDoubleSpinBox / QSpinBox，带合理范围与默认值 f=128、A=1、fs=1024、N=1024）。
- 底部一行：「生成并检测」主按钮 + 「叠加到主图」勾选框。
- 下方 `QTableWidget` 三列「理论值 / 检测值 / 偏差」，两行「频率(Hz)」「幅值」，检测后实时填充；并给一行灰字提示「整周期参数检测最精确，非整周期会出现偏差」。
- 对话框宽度适中，居中弹出，按钮使用系统默认样式，与主窗口协调。

## 交互与反馈
- 勾选「叠加」后每次切换文件/窗函数即时追加曲线并刷新技术图例；未勾选则替换。
- 自验点击「生成并检测」后按钮短暂禁用、完成后恢复并填表；勾选「叠加到主图」时谱曲线追加到主绘图区。
- 失败时状态栏提示，叠加模式不清除已有曲线。
