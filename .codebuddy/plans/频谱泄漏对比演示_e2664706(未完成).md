## 产品概述
在现有信号分析器中新增一组「整周期 / 非整周期」正弦样本文件，并配套一份演示文档，用于在 GUI 中目视对比频谱泄漏现象，并验证矩形窗与汉宁窗对泄漏的抑制作用。不新增程序、不改 GUI、不做多曲线叠加，纯为「样本数据 + 演示文档」。

## 核心功能
- 新增两个参数一致、仅频率是否整周期的单音正弦样本文件：
  - 整周期样本：采样窗口内包含整数个周期，频谱为干净单峰（无泄漏）。
  - 非整周期样本：采样窗口截断非整数个周期，频谱出现明显泄漏（能量扩散到相邻频点）。
- 两份样本的采样率、点数、幅值完全相同，唯一变量为「频率是否为 fs/N 的整数倍」，保证对比公平。
- 配套演示文档：说明背景、样本参数与选取理由、GUI 操作步骤、四种组合（整周期/非整周期 × 矩形窗/汉宁窗）的预期视觉现象、以及答辩讲解话术。
- 在 README 与答辩要点中补充该演示的入口引用。

## 视觉预期
- 整周期 + 矩形窗：128 Hz 处单一尖峰，其余谱线接近 0。
- 整周期 + 汉宁窗：主瓣略变宽，旁瓣极低。
- 非整周期 + 矩形窗：能量扩散到主峰两侧，旁瓣明显抬高、主峰幅值下降。
- 非整周期 + 汉宁窗：旁瓣大幅下降，泄漏被显著抑制，主瓣变宽。

## 技术栈
- 复用现有 Qt/C++ 项目，无代码改动（`SpectrumAnalyzer::amplitudeSpectrum` 已支持传入矩形/汉宁窗）。
- 样本文件为纯文本（首行 `fs=...,N=...`，其后每行一个 double 幅值），沿用 `samples/` 现有命名与格式风格。
- 演示文档为 Markdown，放入 `docs/`。

## 实现策略
### 1. 样本参数（关键决策）
- 采样率 `fs=1024 Hz`、点数 `N=1024`：**N 取 2 的整数次幂**，避免 `SpectrumAnalyzer` 内部的零填充（`nextPowerOfTwo`），使「整周期」呈现为干净单 bin，而非补零后的 sinc 插值形态。
- 整周期样本 `f0=128 Hz`：频率分辨率 `fs/N=1 Hz`，`128 = 128×1`，窗口内正好 128 个完整周期，无截断 → 无泄漏。
- 非整周期样本 `f0=128.5 Hz`：窗口内 128.5 个周期，频率恰好落在 128 与 129 bin 的正中间（半 bin 处），泄漏对称分布到两侧，**对比效果最直观**。
- 幅值 `A=1.0`，两份样本一致。

### 2. 样本生成
- 每份样本共 1025 行：首行 `fs=1024,N=1024`，第 2..1025 行为 `A·sin(2π·f0·i/fs)`，`i=0..1023`，保留 10 位小数（与现有样本精度一致）。
- 用一次性脚本（Python 或 PowerShell）计算生成，不手写 1024 行。
- 生成后自校验：行数=1025、首行格式正确、数值范围在 `[-1,1]`、整周期样本首尾衔接连续。
- 文件命名（`p` 表示小数点，避免文件名含 `.`）：
  - `samples/sine_128Hz_A1_fs1024_N1024.txt`
  - `samples/sine_128p5Hz_A1_fs1024_N1024.txt`

### 3. 演示文档结构（`docs/频谱泄漏对比演示.md`）
- 演示目的与频谱泄漏原理简述（整周期 vs 非整周期、栅栏效应/泄漏、加窗抑制旁瓣）。
- 样本参数表与「为何选 N=1024、f0=128/128.5」的说明。
- GUI 操作步骤：导入 `samples/` 文件夹 → 信号选择「幅值谱」→ 分别选择整周期/非整周期文件 → 切换「矩形窗/汉宁窗」观察。
- 四种组合的预期现象对照表。
- 答辩讲解话术：如何一句话点明「整周期无泄漏、非整周期泄漏、加窗抑制泄漏」。

## 实施要点
- 两份样本除频率外参数完全一致，避免引入其他变量干扰对比。
- N 必须为 2 的幂，否则零填充会改变谱线形态，削弱「整周期无泄漏」的演示效果。
- 非整周期频率取半 bin（.5）位置，使泄漏对称、最明显。
- 文档中的预期现象需与样本参数对应，避免与实际观察矛盾。
